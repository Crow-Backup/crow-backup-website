{{< faq "Can I start a new backup at any time?" >}}
If your friend is online, you can start a new backup at any time. To do this, click on "Start backup" under the corresponding backup in the programme. A new backup will also be created automatically after 24 hours (again, provided your friend is online).
{{< /faq >}}

{{< faq "Do I have to be connected to the same WLAN as my friends to be able to create a new backup?" >}}
No, it also works via the Internet. However, if you are in the same network, it will be faster. This is particularly useful for the first backup or when restoring data.

All your friends are listed on the left-hand side of the program, with a coloured dot next to the icon. If it is red, this means that your friend cannot be reached - so they are probably offline. If it is green, you have a great connection to each other and backups or restores are very fast. A colour in between (yellow/orange) means that you have a connection and a backup or restore of data is possible, but it may be slow.
{{< /faq >}}

{{< faq "How can I improve the connection to my friends and thus make backups and restores faster?" >}}
You can set up port forwarding for port 58300 on your router so that your friends automatically connect directly to you.
{{< /faq >}}

{{< faq "How do I determine how much hard drive space I want to share?" >}}
If you select your friendship in the programme, you can change this. You can also see how much your friend already needs and how much your friend has made available to you.
{{< /faq >}}

{{< faq "What happens if I run out of hard drive space?" >}}
Unfortunately, Crow Backup does not (yet) respond to this automatically. However, you can limit the maximum storage space of your friends in advance so that there is no bottleneck.
{{< /faq >}}

{{< faq "Can I change the shared hard disc space at any time?" >}}
Yes, but your friend's data will not be deleted if your friend has already saved more with you than you (newly) define.
{{< /faq >}}

{{< faq "Can I delete my friends' backups to get more free hard drive space?" >}}
Yes, but it might cost you your friendship. ;-)
{{< /faq >}}

{{< faq "Is it possible that my friend is suddenly deleting my backups?" >}}
Yes, that may be the case. The next time you are online together, you will see this in Crow Backup and you can complain to your friend.
{{< /faq >}}

{{< faq "Can my friends see which files I back up to them?" >}}
No, your data is super-encrypted by you on your computer and your friends only get the encrypted data. This means they have no way of viewing it.
{{< /faq >}}

{{< faq "Why does Crow Backup not load when I restart my computer?" >}}
Crow Backup can only be started automatically if you save your password when you log in.
{{< /faq >}}

{{< faq "How do I know which version of Crow Backup I have installed?" >}}
You should always have the latest version installed automatically. You can see the currently installed version in the settings at the top right.
{{< /faq >}}

{{< faq "Is Crow Backup already completely developed?" >}}
Yes and no, Crow Backup has been fully functional for some time now and backups can be created and files restored. However, we are constantly working on fixing bugs and developing additional functions.
{{< /faq >}}

{{< faq "Can Crow Backup be used worldwide?" >}}
Yes, Crow Backup only requires Internet access... Nevertheless, for legal reasons Crow Backup in its current form is only intended for the Swiss market for the time being.
{{< /faq >}}

{{< faq "How much does Crow Backup cost?" >}}
Crow Backup is free and should remain so.
{{< /faq >}}

{{< faq "How is Crow Backup financed?" >}}
Most of the revenue comes from your friends, who make their storage space available to you. The further development and other running costs are currently covered by donations and crowdfunding.
{{< /faq >}}

{{< faq "How can I support Crow Backup?" >}}
You can help us the most if you use Crow Backup, are happy with it and spread the word. You are also very welcome to [support Crow Backup](/en/support-the-development-of-crow-backup/).
{{< /faq >}}

{{< faq "I would like to give you feedback on your software.What is the best way to do this?" >}}
We are grateful for any feedback, because feedback helps us move forward.The easiest way is to click on "Feedback" at the top of the program and send us your opinion.
{{< /faq >}}

{{< faq "What user data do you store?" >}}
In principle, we want to store as little user data as possible. Nevertheless, we need to store the following types of data in order to ensure an optimal user experience:

-   Data to improve Crow Backup: Analytics data from our website, user feedback submitted
-   Data for operating Crow Backup: Login & security data, current IP addresses so that your friends can find you. Temporarily your encrypted backups in case your friends are not directly reachable.
{{< /faq >}}
