{{< faq "Kann ich jederzeit ein neues Backup starten?" >}}
Sofern dein\*e Freund\*in online ist, kannst du jederzeit ein neues Backup starten. Dazu klickst du im Programm unter dem entsprechenden Backup auf «Backup starten». Ausserdem wird nach 24 Stunden automatisch ein neues Backup erstellt (wiederum sofern dein\*e Freund\*in online ist).
{{< /faq >}}

{{< faq "Muss ich mit demselben WLAN verbunden sein wie meine Freund*innen, um ein neues Backup anlegen zu können?" >}}
Nein, es geht auch über das Internet. Wenn ihr jedoch im gleichen Netzwerk, wird es schneller gehen. Dies ist besonders beim ersten Backup oder beim Wiederherstellen von Daten interessant.  
Im Programm sind links all deine Freund\*innen aufgelistet, neben dem Symbol hat es einen farbigen Punkt. Wenn er rot ist, heisst das, dass dein\*e Freund\*in nicht zu erreichen ist – also vermutlich offline. Wenn er grün ist, habt ihr eine super Verbindung zueinander und Backups oder Wiederherstellungen gehen sehr schnell. Eine Farbe dazwischen (gelb/orange) bedeutet, dass ihr eine Verbindung habt und ein Backup oder ein Wiederherstellen von Daten möglich ist, dies aber langsam sein kann.
{{< /faq >}}

{{< faq "Wie kann ich die Verbindung zu meinen Freund*innen verbessern und damit Backups und Wiederherstellungen schneller machen?" >}}
Du kannst auf deinem Router ein Port-Forwarding für den Port 58300 einrichten, damit verbinden sich deine Freund\*innen automatisch direkt mit dir.
{{< /faq >}}

{{< faq "Wie lege ich fest, wie viel Festplattenspeicher ich freigeben möchte?" >}}
Wenn du im Programm deine Freundschaft anwählst, kannst du dies ändern. Du siehst da auch, wie viel dein\*e Freund\*in bereits braucht und wie viel dein\*e Freund\*in dir zur Verfügung stellt.
{{< /faq >}}

{{< faq "Was passiert, wenn mein Festplattenspeicher knapp wird?" >}}
Crow Backup reagiert darauf leider (noch) nicht automatisch. Du kannst aber im Vorhinein den maximalen Speicherplatz deiner Freund\*innen begrenzen, damit kein Engpass entsteht.
{{< /faq >}}

{{< faq "Kann ich den freigegebenen Festplattenspeicher jederzeit ändern?" >}}
Ja, allerdings werden die Daten deine\*r Freund\*in nicht gelöscht, wenn dein\*e Freund\*in bereits mehr bei dir gespeichert hat, als du (neu) zusicherst.
{{< /faq >}}

{{< faq "Kann ich das Backup meiner Freund*innen löschen, um mehr freien Festplattenspeicher zu bekommen?" >}}
Ja, allerdings kostet das dann eventuell halt deine Freundschaft. ;-)
{{< /faq >}}

{{< faq "Kann es sein, dass mein*e Freund*in plötzlich meine Backups löscht?" >}}
Ja, das kann sein. Wenn ihr das nächste Mal gemeinsam online seid, siehst du dies dann bei dir in Crow Backup und du kannst dich bei deine\*r Freund\*in beschweren.
{{< /faq >}}

{{< faq "Können meine Freund*innen sehen, welche Dateien ich bei ihnen sichere?" >}}
Nein, deine Daten werden von dir auf deinem Computer super verschlüsselt und deine Freund\*innen bekommen nur die verschlüsselten Daten. Damit haben sie keine Möglichkeit sie anzuschauen.
{{< /faq >}}

{{< faq "Warum wird Crow Backup beim Neustart des Computers nicht geladen?" >}}
Crow Backup kann nur automatisch gestartet werden, wenn du beim Anmelden dein Passwort speicherst.
{{< /faq >}}

{{< faq "Woher weiss ich, welche Version von Crow Backup ich installiert habe?" >}}
Du solltest automatisch immer die neuste Version installiert bekommen. In den Einstellungen oben rechts siehst du die aktuell installierte Version.
{{< /faq >}}

{{< faq "Ist Crow Backup bereits fertig entwickelt?" >}}
Jein, Crow Backup ist bereits seit längerem voll funktionsfähig und es können Backups erstellt und Dateien wiederhergestellt werden. Wir arbeiten jedoch stetig an der Behebung von Fehlern und entwickeln weitere Funktionen.
{{< /faq >}}

{{< faq "Ist Crow Backup weltweit nutzbar?" >}}
Ja, Crow Backup benötigt nur Internetzugang… Nichtsdestotrotz ist Crow Backup in seiner jetzigen Form aus juristischen Gründen vorerst nur für den Schweizer Markt bestimmt.
{{< /faq >}}

{{< faq "Wie viel kostet Crow Backup?" >}}
Crow Backup ist kostenlos und soll es auch bleiben.
{{< /faq >}}

{{< faq "Wie finanziert sich Crow Backup?" >}}
Der grösste Teil kommt von deinen Freund\*innen, sie stellen dir ihren Speicherplatz zur Verfügung. Die Weiterentwicklung sowie übrigen laufenden Kosten werden aktuell durch Spenden und einem Crowdfunding gedeckt.
{{< /faq >}}

{{< faq "Wie kann ich Crow Backup unterstützen?" >}}
Du hilfst uns am meisten, wenn du Crow Backup benutzt, glücklich damit bist und es weiterverbreitest. Ausserdem kannst du [Crow Backup sehr gerne unterstützen](/unterstuetze-die-entwicklung-von-crow-backup/).
{{< /faq >}}

{{< faq "Ich möchte euch gerne Feedback zu eurer Software geben. Wie kann ich das am besten tun?" >}}
Wir sind um jedes Feedback dankbar, denn Feedback bringt uns weiter. Am einfachsten ist es, wenn du gleich im Programm oben auf «Feedback» klickst und uns da deine Meinung zukommen lässt.
{{< /faq >}}

{{< faq "Welche Daten über die Benutzer speichert ihr bei euch?" >}}
Grundsätzlich wollen wir so wenig Nutzerdaten wie nur möglich bei uns speichern. Trotzdem müssen wir folgende Arten von Daten speichern, um ein optimales Nutzererlebnis gewährleisten zu können:

-   Daten zur Verbesserung von Crow Backup: Analytics Daten von unserer Website, eingesendete Nutzerfeedbacks
-   Daten zum Betrieb von Crow Backup: Login & Sicherheitsdaten, aktuelle IP-Adressen damit dich deine Freund\*innen finden können. Temporär deine verschlüsselten Backups, falls deine Freunde nicht direkt erreichbar sind.
{{< /faq >}}

{{< faq "Wo werden die Daten standardmässig gespeichert? Wie kann ich diesen Pfad ändern?" >}}
Standardmäßig werden die Sicherungsdaten im Home-Verzeichnis des Benutzers in einem Ordner „.crow“ gespeichert:

-   Windows: %USERPROFILE%\\.crow
-   Mac OS: $HOME/.crow
-   Linux: $HOME/.crow

Es ist möglich, dies in den Einstellungen zu ändern.
{{< /faq >}}

{{< faq "Ist Crow Backup quelloffen (\"Open Source\")?" >}}
Crow Backup bleibt vorerst Closed Source.
{{< /faq >}}

{{< faq "Wäre es möglich, einen eigenen Server zu haben, der temporär die Backup sammelt, anstelle der vordefinierten Crow Backup Server?" >}}
Im Moment ist es nur möglich, unsere vordefinierten Crow-Backup-Server zu verwenden. Dies wird sich in Zukunft ändern, da wir an einer Funktion arbeiten, die dies möglich macht.
{{< /faq >}}

{{< faq "Gibt es eine Crow Backup App für mein Synology NAS?" >}}
Im Moment unterstützen wir Synology NAS noch nicht, aber wir arbeiten daran. Wenn Sie erfahren sind, können Sie Java 21 installieren, den Linux-Installer (.deb) entpacken und ./Crow Backup Daemon starten.
{{< /faq >}}

{{< faq "Kann ich Daten auf mehrere Freunde verteilen, um sie mit einer Raid-Technologie zu sichern?" >}}
Die Unterstützung von RAID 1 ist in der Tat eine Funktion auf unserer Liste, die wir zur Verfügung stellen wollen. Aber im Moment ist noch nicht klar, wann diese Funktion verfügbar sein wird.

Wenn Sie Ihre Daten bis dahin redundant speichern möchten, haben Sie einfach die Möglichkeit, Ihr Backup manuell auf verschiedene Freunde zu verteilen.
{{< /faq >}}

{{< faq "Kann ich meinen eigenen Verschlüsselungsschlüssel verwalten?" >}}
Nein, das ist derzeit nicht möglich.x
{{< /faq >}}

{{< faq "Ist es möglich, die E-Mail Adresse zu ändern und dennoch weiterhin Zugriff auf die Daten zu haben?" >}}
Es ist nicht möglich, die E-Mail Adresse zu ändern (sie wird bei der Verschlüsselung als Salt verwendet). Du kannst jedoch einen neuen Account mit einer neuen E-Mail Adresse anlegen.
{{< /faq >}}

{{< faq "Gibt es eine Versionierung in der Sicherung - und die Möglichkeit, spezifische Versionen wiederherzustellen?" >}}
Backups werden Versioniert und du kannst auch gezielt einzelne Versionen wiederherstellen. Du hast auch die Möglichkeit, Sicherungen wieder zu löschen. Du speicherst die Daten Ordnerweise. Diese kannst du entweder einzeln löschen oder es werden alle Sicherungs-Ordner (=Daten) gelöscht, wenn du eine Freundschaft gänzlich kündest.
