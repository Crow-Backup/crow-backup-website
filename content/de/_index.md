## Bevor ihr startet

{{< faq "Können meine Freund*innen meine Dateien lesen?" >}}
Nein. Crow Backup verschlüsselt deine Dateien auf deinem Computer, bevor sie übertragen werden. Deine Freund\*innen speichern nur die verschlüsselten Daten. Crow Backup verwendet Ende-zu-Ende-Verschlüsselung (AES-256).
{{< /faq >}}

{{< faq "Wie viel Speicherplatz brauchen wir?" >}}
In den Einstellungen eurer Freundschaft legt ihr einzeln fest, wie viel Platz ihr anbietet. Fangt klein an und plant später genügend Platz für eure Dateien und Backup-Versionen ein. Crow Backup passt die Limiten derzeit nicht automatisch an, wenn die Festplatte voll wird. Prüft deshalb den freien Speicherplatz.
{{< /faq >}}

{{< faq "Müssen beide Computer online sein?" >}}
Für ein Backup oder eine Wiederherstellung muss der Computer deiner Freund\*innen erreichbar sein. Die Verbindung funktioniert über das Internet; ihr braucht nicht dasselbe WLAN. Im gleichen lokalen Netzwerk kann ein grosses erstes Backup oder eine Wiederherstellung schneller gehen.
{{< /faq >}}

{{< faq "Was passiert, wenn mein Backup gelöscht wird oder jemand Crow Backup nicht mehr nutzt?" >}}
Diese Kopie steht dir dann möglicherweise nicht mehr zur Wiederherstellung zur Verfügung. Sprecht euch ab, bevor ihr gespeicherte Backups löscht oder eine Freundschaft beendet, und bewahrt eine weitere unabhängige Sicherung wichtiger Dateien auf. Wenn ihr eine Freundschaft in Crow Backup beendet, werden die zugehörigen Backups gelöscht.
{{< /faq >}}

{{< faq "Sind Server von Crow Backup beteiligt?" >}}
Ja. Crow Backup betreibt Dienste für Konten und Verbindungen. Die Server können ausserdem vorübergehend verschlüsselte Backups speichern, wenn Freund\*innen nicht direkt erreichbar sind. Deine Freund\*innen erhalten verschlüsselte Dateien. Mehr dazu in den [FAQ](/faq/).
{{< /faq >}}

{{< faq "Warum ist Crow Backup kostenlos?" >}}
Ihr stellt den Speicherplatz zur Verfügung. Die Entwicklung und die laufenden Kosten werden durch Spenden unterstützt. Crow Backup ist kostenlos und soll es bleiben.
{{< /faq >}}

{{< faq "Wo ist Crow Backup verfügbar?" >}}
Crow Backup kann sich weltweit über das Internet verbinden. Aus rechtlichen Gründen ist es derzeit für den Schweizer Markt bestimmt. Weitere Informationen findest du in den [FAQ](/faq/).
{{< /faq >}}

### Was ist Crow Backup?

{{< video "/wp-content/uploads/2024/03/Was-ist-Crow-Backup.mp4" >}}

{{< faq "Backup-Möglichkeiten vergleichen" >}}
Crow Backup, Cloud-Backups und lokale Backups im Vergleich
| Merkmal | Crow Backup | Cloud-Backup | Lokales Backup |
| --- | --- | --- | --- |
| Kosten | Kostenlose Software; ihr stellt den Speicherplatz bereit | Abhängig von Anbieter und Speicherplan; oft laufende Gebühren | Benötigt vorhandenen Speicherplatz oder ein separates Laufwerk |
| Privatsphäre | Ende-zu-Ende-verschlüsselt; Freund\*innen speichern verschlüsselte Dateien | Verschlüsselung und Zugriff des Anbieters hängen vom Dienst ab | Verschlüsselung hängt von Software und Einstellungen ab |
| Kontrolle | Du wählst Freund\*innen, Ordner und Speicherlimiten | Funktionen und Aufbewahrung hängen vom Anbieter ab | Du verwaltest Gerät, Software und Backup-Zeitplan |
| Speicherort | Computer von Freund\*innen; Crow-Server können verschlüsselte Backups vorübergehend speichern | Infrastruktur des Anbieters | Dort, wo du das Backup-Laufwerk aufbewahrst |

Bewahre eine weitere unabhängige Kopie wichtiger Dateien auf. Bei Crow Backup hängt die Wiederherstellung davon ab, dass dein Backup noch vorhanden und dein\*e Freund\*in erreichbar ist.
